## Overview

Standard SSL assumes labelled and unlabelled data share a common marginal
distribution. Spatial dependence alone doesn't violate this — labelled and
unlabelled locations are typically draws from the same underlying spatial
process. What violates it is the **sampling mechanism**: spatially biased or
preferential site selection makes the marginals genuinely diverge. We treat
marginal mismatch, spatial autocorrelation, and spatial non-stationarity as
three distinct mechanisms, and ask how mismatch degrades SSL, whether the
cluster, manifold, and low-density-separation assumptions survive it, and how
the resulting failure can be diagnosed.

Using a controlled synthetic framework alongside PovertyMap-WILDS, California
housing, socio-economic, and US air quality data, we vary mismatch severity
while independently controlling for autocorrelation and non-stationarity,
across a ten-method comparison, a distribution-aware mitigation framework, and
calibration/divergence diagnostics (a segmented-regression changepoint
analysis and a kernel-weighted local divergence estimator).

SSL performance doesn't degrade gradually — it shows a **threshold-like
breakdown** around α ≈ 0.71–0.77. Spatial non-stationarity degrades
performance independently of marginal mismatch, and affected models become
increasingly **overconfident** precisely where they are most wrong.

## Methods compared

| Family | Methods | Notes |
|---|---|---|
| Baselines | Supervised-only, Self-training, Label propagation | Main-text focus; operationalise no/cluster/manifold assumptions |
| Distribution-aware | Re-weighted self-training, full 3-component framework | Density-ratio re-weighting + spatial weighting + adaptive pseudo-labelling |
| Consistency-based | Mean Teacher, FixMatch | Gaussian-noise perturbation in place of image augmentation |
| Graph-based | GCN, spatial-kernel GCN | Transductive, $k$-NN or Gaussian-weighted spatial graph |
| Spatially explicit | GNNWR | Geography-only, no covariate fallback |
| Geostatistical | Geostatistical SSL | Conditional-simulation pseudo-labelling, following Fouedjio & Talebi (2022) |

## What is covered


The experiments distinguish spatially biased sampling, spatial dependence,
and non-stationarity. They compare prediction and calibration across sampling
severity, evaluate divergence diagnostics, and investigate mitigation and
spatial methods. Synthetic breakpoint estimates are descriptive, not validated
thresholds for deployment. Real-data conclusions depend on the geographic split.

Use Python 3.10 or newer; the code contains modern union type syntax.


## NOTE
The notebooks provide easy implemntations of the analysis performed. For the exact condiguration that establishes the results in this work use the following commands below.

```bash
git clone https://github.com/Wiredu2020/Distributional-Mismatch-in-Spatial-SSL-Application.git
cd Distributional-Mismatch-in-Spatial-SSL-Application
python -m venv .venv
```

Activate it on Linux/macOS:

```bash
source .venv/bin/activate
export PYTHONPATH="$PWD/src"
```

Or in Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
$env:PYTHONPATH = "$PWD\src"
```

Install the full requirements:

```bash
python -m pip install -r requirements.txt
```

For the synthetic baseline smoke test only, the smaller dependency set is:

```bash
python -m pip install numpy scipy scikit-learn pandas matplotlib pyyaml
```

The full requirements also include PyTorch, GSTools, WILDS, Requests,
OpenPyXL, and `pwlf`. Neural models require PyTorch; the geostatistical method
requires GSTools. The baseline test uses a CPU and does not need a GPU or
external data. Full-run time and memory depend on sample sizes and methods;
no universal laptop runtime is claimed.

For configuration options, output interpretation and worked examples, see
[docs/USER_GUIDE.md](docs/USER_GUIDE.md).

```bash
python -m ssl_spatial.experiments.controlled_experiment configs/smoke_test.yaml
```

## Reproduce the twenty-seed experiments

These commands match the repository's module and configuration names:

```bash
python -m ssl_spatial.experiments.controlled_experiment configs/controlled_experiment_v2.yaml
python -m ssl_spatial.experiments.localized_mmd_analysis_v2
python -m ssl_spatial.experiments.controlled_experiment configs/controlled_experiment_sensitivity.yaml
python -m ssl_spatial.experiments.changepoint_analysis
```

The main synthetic sweep contains 2,160 fitted models: 6 severities × 3
length-scales × 2 non-stationarity levels × 20 seeds × 3 methods. The original
`controlled_experiment.yaml` is a three-seed, 324-model exploratory version;
use the `_v2` configuration for the main twenty-seed analysis.

Prepare data as described in [docs/DATA.md](docs/DATA.md), then run:

```bash
python -m ssl_spatial.experiments.wilds_benchmark configs/wilds_benchmark_v2.yaml
python -m ssl_spatial.experiments.real_world_benchmark configs/housing_benchmark_v2.yaml

python -m ssl_spatial.experiments.real_world_benchmark configs/air_quality_benchmark_v2.yaml

python -m ssl_spatial.experiments.neural_da_ssl_v2 configs/neural_da_ssl_v2.yaml
```
